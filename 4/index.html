1. FITTING A NEURAL FIELD TO A 2D IMAGE

model architecture

for part 1, i used a basic mlp that takes in 2d pixel coordinates (with positional encoding) and predicts the rgb color at each pixel.

i used positional encoding with L = 10.

my network had width 256 and looked like this:

dense(input_dim → 256) → relu
dense(256 → 256) → relu
dense(256 → 256) → relu
dense(256 → 3) → sigmoid

the sigmoid at the end keeps the output in the range (0, 1), which matches the normalized pixel colors.

for training, i used: batch size = 10000, 1000 epochs, adam optimizer (learning rate = 5e-4), and MSE loss. every 200 epochs i saved a predicted image to see how the model was learning.

2. NEURAL RADIANCE FIELD FROM MULTIVIEW IMAGES

implementation summary (2.1–2.5)

for 2.1, I wrote functions to move between coordinate spaces. transform() converts camera-space points to world space using homogeneous coordinates and the c2w matrix. pixel_to_camera() undoes the intrinsics by multiplying with inv(K) and scaling by depth. in pixel_to_ray() i take the pixel location, turn it into a direction in camera space, rotate it with the c2w rotation, and repeat the camera center to get the ray origins. this gives a ray origin and normalized ray direction for every pixel.

for 2.2 + 2.3, i implemented sampling in sample_along_rays() and made it batched to be fast with PyTorch. i made a RaysData class that builds all rays for all images ahead of time. inside the constructor, i create an (H*W) pixel grid, unroll the images, and use pixel_to_ray() for each c2w to precompute rays_o, rays_d, and pixel colors. sample_rays() then just picks random rays from the full set.

for 2.4, i built the nerf network using three pieces: a base mlp (nerf_base_model) that outputs a 256-dim feature, a density head (nerf_density_model) that predicts sigma, and a color head (nerf_color_model) that predicts rgb from the feature plus the positional-encoded view direction. points use positional encoding with L=10, and directions use L=4.

for 2.5, i implemented the volume rendering equation in volrend. i convert density to alpha, compute the running transmittance with cumulative products, and take a weighted sum of all sample colors along the ray to get the final pixel color. this is what the training loop compares against the ground truth rgb.
